Start a work session in this repo.

1. Run `git status`. If there are uncommitted changes, stop and tell me; do not pull over them.
2. Run `git pull --ff-only`. If it fails because the branches diverged, explain what happened in plain terms and stop.
3. Read `NOTES.md`. If it does not exist, say so.
4. Give me a short summary (3-6 lines): current status per NOTES.md, what the last session did, any open items. If NOTES.md names a manuscript location, remind me that manuscript work happens there, not in this repo.
5. Ask what I want to work on. Do not start anything until I answer.
